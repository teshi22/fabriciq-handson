# Fabric IQ ハンズオン

Microsoft Fabric / Fabric IQ のハンズオンで使用するデータをまとめたリポジトリです。

## 事前準備

主催者・管理者向けの環境準備は [事前準備](./preparation.md) を参照してください。容量・費用、ライセンス、テナント設定、受講生のワークスペース作成・容量割り当てに必要な権限、アクセス管理をまとめています。

## ハンズオン

受講生の操作手順は [ハンズオン](./handson.md) を参照してください。

製造業シナリオの課題は [演習編](./exercises.md) を参照してください。

## データ

- [製造業データ：ロット・設備異常調査](./data/02_製造業データ/README.md)：精密部品工場を想定した架空データです。製品・設備を各20件、製造記録を500件、製品不良・設備異常を各100件用意しています。工程名は製造記録に含めています。[オントロジー設計](./ontology-design.md)も参照してください。
